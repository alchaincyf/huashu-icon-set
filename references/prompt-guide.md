# 图标生图 Prompt 指南

本文件供 Step 1（风格锚点）、Step 2a（网格批量，默认）、Step 2b（逐个生成，精度兜底）编写生图 prompt 时参考。

## 1. 核心原则

1. **中文短句**：每条 prompt 用简短中文句子，一句说一件事，不用长复合句。
2. **真实风格参考名**：用设计领域公认的风格名称（见下表），不堆"高端、大气、精致、简约"等形容词。
3. **具象名词优先**：用"剪刀"不用"矩形四个角各有L形短线"；用"向左U形回转箭头"不用"撤销箭头"。模型对具象名词理解远好于几何描述。
4. **默认网格批量生成**：16 个图标拼一张 4×4 网格图，切完靠自检挑出对不齐/画错的，单独重生那几个（不是重出整张）。逐个单图生成降级为精度兜底手段，见第 5 节。
5. **纯色背景**：必须用高饱和纯色背景（绿色 #00FF00），禁止白色/浅色背景（与白色底座无法分离）。
6. **可识别性优先**：每个图标用最通用的视觉隐喻（盾牌=安全、心形=收藏、齿轮=设置），不追求猎奇。

## 2. 风格方向参考名（Step 1 用）

一次出 3–4 个方向时，从下表挑差异明显的风格，每张只换风格名、其余描述保持一致。

| 风格名 | 特征 | 适用场景 |
|---|---|---|
| iOS 扁平化图标 | 面性纯色块、无描边或极细描边、连续圆角 | App 功能入口、Tab 栏 |
| Material Design 图标 | 几何感、网格对齐、系统级规范 | Android / Web 工具类 |
| 线性描边图标 | 等宽单线勾勒、2px 圆角端点、无填充 | 后台管理、工具栏、导航 |
| 双色线面图标 | 外轮廓线性 + 局部主色填充强调 | 现代 SaaS、数据面板 |
| 填充色图标 | 实心填充、高饱和、无描边 | 标签、状态标记、底部导航 |
| 轻拟物图标 | 微渐变、柔和投影、圆角矩形底 | 产品功能卡片、桌面端 |
| 玻璃拟态图标 | 半透明毛玻璃、模糊高光、浅色描边 | 暗色主题、展示页 |
| 手绘涂鸦图标 | 不规则线条、微抖动、手写感 | 教育、创意、社区类 |
| 像素风图标 | 低分辨率像素块、有限色板 | 游戏、复古主题 |
| 双色扁平图标 | 主色 + 辅色两个色块、无渐变 | 品牌感强的 C 端产品 |

## 3. 背景色策略（🔴 关键）

AI 生图模型**不输出真正的透明背景**（输出 RGB 无 alpha），必须生成纯色背景再用代码抠除。

**核心原则：背景色必须与图标所有颜色有高色相差异，使颜色键控能精确分离。**

| 图标类型 | 背景色 | prompt 写法 | 抠图方式 |
|---|---|---|---|
| 普通图标（无绿色元素） | 纯绿色 `#00FF00` | "纯绿色背景色值#00FF00，背景均匀无渐变无阴影，图标中不能出现任何绿色" | 绿色键控（最鲁棒，对投影容错好） |
| 含绿色的品牌色图标（微信等） | 纯蓝色 `#0000FF` | "纯蓝色背景色值#0000FF，背景均匀无渐变无阴影，图标中不能出现任何蓝色" | 蓝色键控 |
| 不含绿色的品牌色图标（小红书/B站等） | 纯绿色 `#00FF00` | 同普通图标模板 | 绿色键控 |

**禁止**：
- 白色/浅灰背景（与白色底座无法分离）
- 透明背景（模型不输出 alpha）
- 品红色/黄色等"中间色"背景 + flood fill（方向性投影形成渐变色带，容差小了残留、大了误删，不可靠）
- 渐变背景

**经验**：绿色键控对轻拟物投影最鲁棒——投影混合后的暗绿色仍满足 `g > r + margin` 条件，能被干净移除。只有当图标本身含绿色时才换蓝色背景。

## 4. Step 1 风格锚点 prompt 模板

```
一个[图标语义，如"麦克风"]图标，[风格名]风格，
[风格细节，如"白色圆角矩形底座带柔和投影，灰色话筒线条"]，
纯绿色背景色值#00FF00，背景均匀无渐变无阴影，
图标中不能出现任何绿色，
正方形构图，图标居中占画面70%，无文字，2D矢量图形
```

生成 3–4 张时：
- 用 `image_gen`，尺寸 1:1（2048×2048）。
- 每张只替换 `[风格名]` 和 `[风格细节]`，语义和其余描述完全一致，确保差异仅来自风格。
- 把候选图全部给用户，明确标注每张对应的风格名，让用户选。
- **选定后必须用 `scripts/chroma_key.py` 跑一次抠图验证**，确认背景干净移除、主体完整再进 Step 2。

## 5. Step 2a 网格批量 prompt 模板（默认路径）

16 个图标一组，一次 `image_gen` 出一张 2048×2048 网格图，垫图 URL 传入 `image_reference_url_list`。

```
一张2048x2048正方形图，4行4列网格排列16个图标，
纯绿色背景色值#00FF00铺满全图，背景均匀无渐变无阴影，
16个图标之间用背景色隔开，每个图标独占一格，格子间留白不小于画面5%，不画分隔线，
风格：[风格名]风格，[风格细节，与锚点一致]，图标元素为灰色，不能出现任何绿色，无文字，
16个格子从左到右、从上到下依次是：
1.[具象名词] 2.[具象名词] 3.[具象名词] ... 16.[具象名词]
```

写这 16 条具象名词时用第 7 节的对照表，和逐个生成模板要求完全一样——网格批量不是降低描述精度，只是把 16 次调用合成 1 次。

**格子留白比不画分隔线更重要**：靠背景色间距让 `slice_grid.py` 按等分网格裁的时候不会切到相邻图标；画了分隔线反而可能被误判成图标的一部分。

不足 16 个的最后一组按实际数量调整行列（12 个用 4×3、9 个用 3×3），prompt 里的网格描述和编号列表跟着改。

## 6. Step 2b 逐个生成 prompt 模板（精度兜底）

网格批量里对不齐、画错、或本来就要求高精度的图标，单独用一个 `image_edit` request 重做，垫图 URL 传入 `image_reference_url_list`。

### 普通图标模板

```
一个[具象名词描述，如"剪刀"/"放大镜中间加号"/"向左U形回转箭头"]图标，
[风格名]风格，[风格细节，与锚点一致]，
纯绿色背景色值#00FF00，背景均匀无渐变无阴影，
图标中不能出现任何绿色，所有图标元素为灰色，
图标居中占画面70%，无文字，2D矢量图形
```

### 品牌色图标模板

不含绿色的品牌色（B站、小红书等）用绿色背景，和普通图标模板相同。

含绿色的品牌色（微信等）用蓝色背景：

```
[平台名]图标[品牌色描述，如"绿色圆角方形中间两个白色对话气泡"]图标，
[风格名]风格，柔和投影，
纯蓝色背景色值#0000FF，背景均匀无渐变无阴影，
图标中不能出现任何蓝色，
图标居中占画面70%，无文字，2D矢量图形
```

常见品牌色：
- B站：粉蓝渐变（`#FB7299` → `#00A1D6`），白色小电视机（带天线和按钮）→ 绿色背景
- 小红书：红色（`#FF2442`），白色摄像机 → 绿色背景
- 微信：绿色（`#07C160`），白色对话气泡 → 蓝色背景

### 对称图标技巧

chevron-up/down、undo/redo 等对称图标，如果 AI 反复画不准方向，**直接用 PIL 翻转已生成的另一半**，100% 精确：

```python
from PIL import Image
img = Image.open("chevron-down.png").convert('RGBA')
img.transpose(Image.FLIP_TOP_BOTTOM).save("chevron-up.png")
# 左右对称用 Image.FLIP_LEFT_RIGHT
```

### 具象名词对照表

写 prompt 时优先用左列具象名词，不要用右列几何描述：

| 用这个 ✅ | 不要用 ❌ |

| 剪刀 | 矩形四个角各有L形短线 |
| 放大镜中间加号 | 圆形镜片加十字 |
| 向左U形回转箭头 | 撤销箭头/弯曲箭头 |
| 垃圾桶带盖子 | 垃圾桶 |
| 眼睛有眼眶和瞳孔 | 眼睛图标 |
| 喇叭加三道声波 | 扬声器 |
| 话筒 | 麦克风 |
| 摄像机加斜杠 | 摄像头关闭 |
| 山和太阳的图片 | 照片图标 |
| 鼠标箭头光标 | 光标 |

## 7. 生成后检查清单（网格批量、逐个生成都要过）

抠图前先检查原图（网格批量对整张图逐格看，逐个生成对每张单独看），任一不满足就重新生成该图标——网格批量时只重生问题那一格，不重出整张：

- [ ] 背景是均匀纯色（绿色/蓝色），无渐变、无阴影、无杂色
- [ ] **图标元素不含背景色**（绿色背景上没有绿色图标元素；蓝色背景上没有蓝色图标元素）
- [ ] 语义准确（一眼能认出是什么，用具象名词验证）
- [ ] 图标居中，不偏到一边，**网格批量额外看：没有跨到相邻格子**
- [ ] 图标占画面约 70%，不贴边、不过小
- [ ] 无文字、无字母（品牌名也不行，用图标隐喻）
- [ ] 风格与锚点一致（底座、线宽、圆角、投影）

抠图后检查：

- [ ] 四角完全透明（alpha = 0）
- [ ] 图标主体完整无缺损
- [ ] 边缘无背景色残留（绿边/蓝边）
- [ ] 图标居中，四周留白均匀
- [ ] 视觉重量与其他图标一致
